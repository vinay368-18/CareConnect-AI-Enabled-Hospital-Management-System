# CareConnect Retinal AI Microservice (`cvd-ai-service`)

Production REST API service for deep learning multi-task retinal screening, integrated with the **CareConnect Hospital Management System (HMS)**.

---

## 1. Clinical Scope & Research Boundaries

> [!WARNING]
> **Mandatory Clinical Safety Notice**:
> - **Experimental Research Screening**: Vascular disease (CVD) predictions are assistive indicators generated by a deep convolutional network (EfficientNet-B0 backbone). In held-out test evaluation ($N=191$ patients), image-only discrimination for systemic vascular disease yields **ROC-AUC: 0.5202** (95% CI: `[0.3936, 0.6416]`), indicating near-chance discrimination without systemic clinical biomarkers.
> - **Not a Medical Diagnosis**: This service does **not** diagnose cardiovascular disease, myocardial infarction, or diabetes.
> - **Ocular vs. Systemic Separation**: Diabetic Retinopathy (DR) grading reflects visible ocular microvascular pathology (**76.99% test accuracy**, **0.6918 Weighted F1**) and does **not** indicate cardiovascular disease status or accuracy.
> - **Mandatory Physician Review**: All findings must be clinically correlated with physical examinations, sphygmomanometer blood pressure readings, fasting lipid panels, and standard 12-lead electrocardiography (ECG).

## 2. API Endpoints

The service runs on `http://127.0.0.1:5000` (FastAPI / Uvicorn).

### `GET /health`
Verifies microservice availability, PyTorch model status, and device metadata.

**Response (HTTP 200)**:
```json
{
  "status": "healthy",
  "model_loaded": true,
  "model_version": "2.0.0-experiment_b",
  "architecture": "CareConnectMultiTaskNet (EfficientNet-B0)",
  "device": "cpu",
  "vessel_model_loaded": true,
  "tasks": ["vascular_disease", "systemic_hypertension", "dr_grade"]
}
```

### `POST /predict`
Performs multi-task screening on an uploaded retinal fundus photograph.

* **Method**: `POST`
* **Content-Type**: `multipart/form-data`
* **Form Field**: `file` (Binary JPEG / PNG image, maximum 25 MB, minimum $64 \times 64$ pixels)
* **Response (HTTP 200)**:
```json
{
  "status": "success",
  "model_version": "2.0.0-experiment_b",
  "cvd_prediction": "Positive",
  "cvd_probability": 0.5907,
  "cvd_threshold": 0.4996,
  "hypertension_prediction": "Positive",
  "hypertension_probability": 0.4999,
  "hypertension_threshold": 0.4288,
  "dr_grade": "No DR",
  "dr_confidence": 0.6535,
  "dr_probabilities": {
    "No DR": 0.6535,
    "Mild": 0.1842,
    "Moderate": 0.1012,
    "Severe": 0.0411,
    "Proliferative": 0.0200
  },
  "risk_level": "Experimental Screening - Requires Clinical Review",
  "recommendation": "Experimental AI research output. Complete comprehensive cardiovascular risk assessment (blood pressure, fasting lipid panel, 12-lead ECG) by an attending physician is mandatory.",
  "reliability_badge": "Low reliability: image-only discriminative performance on systemic vascular disease is near chance (Test ROC-AUC: 0.5202). Not a diagnostic test.",
  "clinical_caveats": "Retinal image-only models exhibit weak discrimination for systemic vascular disease (Test ROC-AUC: 0.5202; 95% CI: 0.3936–0.6416). Diabetic Retinopathy accuracy (76.99%) reflects direct ocular pathology and does NOT indicate cardiovascular disease accuracy.",
  "experimental_flag": true
}
```

### `POST /predict-base64`
Accepts base64 encoded image string in JSON payload (`{"image_base64": "..."}`).

### `POST /segment`
Optional Residual U-Net retinal vessel segmentation. Returns PNG binary overlay and `X-Vessel-Density` header.

## 3. Windows Setup & Execution Instructions

### Prerequisites
- Python 3.10 – 3.12 (Virtual environment `cvd-env` located at `C:\Users\vinay\cvd-env`)
- PyTorch 2.14+ (CPU or CUDA)
- FastAPI 0.142+ & Uvicorn 0.54+

### Starting the Service
Open PowerShell in the project directory:

```powershell
# Navigate to the project root
cd "C:\Users\vinay\javacode\HospitalManagementSystem Project"

# Launch the FastAPI REST service on port 5000
& "C:\Users\vinay\cvd-env\Scripts\python.exe" "cvd-ai-service\api_server.py"
```

The service will output:
```
INFO:     Started server process [PID]
INFO:     Waiting for application startup.
INFO:cvd-api:[CVD API] Initializing CareConnect Retinal AI microservice...
INFO:cvd-inference:CareConnectMultiTaskNet model loaded successfully on CPU.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:5000 (Press CTRL+C to quit)
```

### Running Automated Service Tests
```powershell
& "C:\Users\vinay\cvd-env\Scripts\python.exe" "cvd-ai-service\test_ai_service.py"
```
